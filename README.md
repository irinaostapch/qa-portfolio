# QA Automation Portfolio | TypeScript + Playwright

This repository demonstrates skills in UI and API test automation.

## Tech Stack
*   **Language:** TypeScript
*   **Test Framework:** Playwright
*   **Pattern:** Page Object Model (POM)
*   **API Testing:** Axios
*   **CI/CD:** GitHub Actions
*   **Reporting:** Playwright HTML Reporter

## How to Run
1.  Clone: `git clone https://github.com/irinaostapch/qa-portfolio.git`
2.  Install: `npm install`
3.  Run tests: `npx playwright test`
4.  View report: `npx playwright show-report`
